## 使用边界

- Docker 应挂载整个配置目录到 /cfg。单文件绑定挂载可能不允许原子替换；此时保存会报错并保留旧文件，不回退到可能截断文件的写法。
- 临时文件刷盘不等于整目录断电持久性保证；未增加目录 fsync，也未承诺保留全部 Windows ACL 或原文件所有者信息。
- 本轮处理 Recorder 层已成功启动资源的回滚。组件内部部分初始化后失败、回滚清理本身再次失败、持续不返回的外部回调，仍需更深层故障测试，不能承诺所有故障均能自动恢复。
- aiohttp 连接器生命周期、IPv4 配置解析、循环导入和长期运行资源占用留待独立维护阶段，不混入本轮。
